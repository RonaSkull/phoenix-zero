# Pay‑Per‑Execution (PPE) — Go‑Live Pack

Este diretório contém a documentação **organizada e separada** do produto **Pay‑Per‑Execution** ("produto dentro do produto") para ir live sem confundir com o restante do Phoenix Zero.

## Definição curta (1 frase)
**Execução de agentes de IA condicionada a pagamento, com prova verificável, sem humanos no loop.**

## O que este pack NÃO é
- Não é um redesign do produto inteiro.
- Não é um split de repositório.
- Não é um marketplace.
